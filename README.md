# ResearchHub LK — Interactive Research Portfolio Website

## Project Overview
**ResearchHub LK** is a responsive, multi-page web application created to showcase Sri Lankan academic research, innovation projects, and cross-disciplinary studies across Technology, Environment, and Management.

## Project Structure
```text
ResearchHub-LK/
├── index.html        # Home page with hero banner, core research domains, and statistics
├── portfolio.html    # Dynamic research showcase with category filtering, images, and modal view
├── contact.html      # Contact details and JavaScript-validated inquiry form
├── style.css         # Responsive CSS (Flexbox & Grid), custom theme variables, dark mode, and animations
├── script.js         # Mobile hamburger menu, dark mode switcher, JSON fetch, and form validation
├── projects.json     # Structured JSON dataset containing research publications and image URLs
└── README.md         # Project documentation
